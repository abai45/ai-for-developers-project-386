# Экраны «Календаря звонков»

Структура секций и каноны экрана. Источник истины формулировок —
`docs/decisions.md` (секции «Общие секции screens.md», «Экран владельца
`/owner`», «Экран гостя `/book`», «Главный экран») и спецификация #6;
этот файл — указатель и порядок, тексты не дублирует.

## Порядок секций

1. **Общие правила** — четвёрка состояний `loading/empty/error/ok` у каждой
   секции экрана; канонические тексты; ошибки секций — инлайном, тосты
   (Sonner) — только исходы submit; адаптив mobile-first с переломом `md`
   (768px); доступность: видимый фокус, один `h1` на экран, `role="alert"`.
2. **Лендинг `/`** — заголовок и текст из задания, кнопка «Начать работу» →
   `/book`, ссылка «Владелец» в футере → `/owner`.
3. **Владелец `/owner`** — `h1` «Владелец»; секции: «Создать тип встречи»,
   «Типы встреч», «Предстоящие встречи»; мобилка — столбец, `md` — форма
   слева, списки справа; секции грузятся параллельно и независимо.
4. **Гость `/book`** — мастер из 4 шагов («Тип» → «Календарь» → «Имя» →
   «Подтверждение») со степпером и инфо-карточкой на шагах 2–4; состояние
   мастера — в памяти (F5 → шаг 1); экран «Вы записаны» — `/book/success`
   (без состояния мастера → редирект на `/book`).
