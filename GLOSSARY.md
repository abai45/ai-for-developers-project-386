# Календарь звонков

Сервис бронирования встреч: владелец публикует типы встреч, гость записывается на свободный слот.

## Language

**Владелец**:
Один заранее заданный профиль без авторизации; заводит типы событий и видит предстоящие встречи всех типов одним списком. Доступ к его части — по прямой ссылке, гостям не показывается.
_Avoid_: админ, пользователь, координатор

**Гость**:
Тот, кто записывается на встречу; приходит без регистрации и называется только именем.
_Avoid_: посетитель, клиент, пользователь

**Тип встречи**:
Шаблон будущей встречи: название, описание, длительность и шаг слотов.
_Avoid_: событие, мероприятие, формат

**Слот**:
Кандидат-интервал для записи: начало плюс длительность типа, возникающий по шагу типа внутри рабочего времени.
_Avoid_: интервал, окошко, timeslot

**Встреча**:
Слот, выбранный гостем на своё имя; единица, которая появляется в списке владельца.
_Avoid_: бронь, бронирование, booking

**Подключение к встрече**:
Синоним записи на встречу: отдельного «входа» в встречу в проекте нет.
_Avoid_: вход в встречу, join

**Свободный слот**:
Слот, чей интервал не пересекается ни с одной встречей любого типа.
_Avoid_: доступное время, окно

**Занятый слот**:
Слот, чей интервал пересекается с существующей встречей; показывается гостю без данных о том, кто занял.
_Avoid_: заблокированный, недоступный

**Окно записи**:
Период, в котором гость может выбрать слот: 14 календарных дней, начиная со следующего дня.
_Avoid_: горизонт, диапазон, промежуток

**Рабочее время**:
Ежедневный интервал, в котором могут начинаться встречи владельца: с 09:30 до 18:00 в поясе Asia/Almaty.
_Avoid_: часы работы, расписание дня

**Шаг слота**:
Расстояние между соседними началами слотов одного типа встречи.
_Avoid_: инкремент, периодичность

**Предстоящие встречи**:
Список владельца: только встречи, ещё не начавшиеся, по времени начала.
_Avoid_: история, календарь встреч

**Мастер записи**:
Путь гостя от списка типов встреч до подтверждения записи; гость может вернуться на любой пройденный шаг.
_Avoid_: визард, wizard, форма записи

**Шаг мастера**:
Одна из четырёх ступеней мастера записи: тип, календарь, имя, подтверждение.
_Avoid_: этап, экран бронирования

**Экран «Вы записаны»**:
Финальный экран после успешной записи: тип встречи, имя гостя, начало и окончание.
_Avoid_: страница успеха, спасибо, success
